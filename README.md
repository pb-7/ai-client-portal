# Fake Financial Firm Client Portal

A lean, single-application Next.js foundation for the future Fake Financial Firm client portal. It currently contains only a responsive branded landing/login placeholder—no authentication, database, AI, or financial-data functionality.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- pnpm

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
pnpm lint
pnpm build
```

Future application code should follow the agreed `src/app`, `src/components`, `src/lib`, `src/types`, `src/constants`, `supabase/migrations`, and `docs` structure.
